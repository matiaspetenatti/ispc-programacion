# Titulo
Sistema de control de stock para empresa de máquinas de ensamble.


## Descripción 


Objetivo principal: Controlar el inventario de insumos que ingresan a través de proveedores y egresan mediante los pedidos internos de las diferentes áreas de producción de la empresa (no está orientado a ventas comerciales).

Estructura de Datos: Incluye un Diagrama Entidad-Relación (DER) que modela componentes clave como Productos, Stock, Movimientos, Compras, Pedidos, Proveedores, Áreas y Empleados de depósito.

Tecnología e Interfaz: La aplicación se programa en Python, utiliza bases de datos con sentencias SQL y su interfaz gráfica se diseña mediante la librería Tkinter, contemplando pantallas para inicio de sesión, consulta de stock, ejecución de pedidos e ingreso de mercadería.

Organización: El equipo de 5 integrantes (Agustín Rosa, Ian Montoya, Jessica Pereyra, Matias Petenatti y Jonathan Piedrabuena) tiene roles distribuidos de forma clara en áreas de coordinación, modelado de datos, diseño de interfaz, acceso a datos, validaciones y documentación.
